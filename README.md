# criacao-de-videos

Repositório **público** com materiais de vídeo: logos, molduras, layouts, artes de divulgação e trailers.

Existe para que ferramentas de vídeo (vidIQ, OpusClip, HyperFrames, Fenaky, Canva etc.) consigam acessar os arquivos por um **link público**.

## Pastas

| Pasta | O que vai nela |
|---|---|
| `gta-loucura/` | Página @gta6_loucura: plaquinha, molduras, layouts e scripts |
| `andre-varela/` | Marca pessoal AV: logo e artes públicas |
| `games/` | Divulgação de games (trailers, comerciais da Steam), uma subpasta por jogo |

## Link público de um arquivo

```
https://raw.githubusercontent.com/andrervarella/criacao-de-videos/main/<caminho-do-arquivo>
```

Exemplo: `https://raw.githubusercontent.com/andrervarella/criacao-de-videos/main/gta-loucura/logo/plaquinha-gta-loucura.png`

## Regra de ouro

Tudo aqui é visível para qualquer pessoa, **para sempre** (o histórico do Git guarda até o que for apagado).

- ✅ Pode: logo, moldura, layout, arte e vídeo de divulgação que vão ser postados de qualquer jeito.
- ❌ Não pode: dados de alunos, senhas e chaves, documentos pessoais, ou arte e roteiro de jogo que ainda devem ficar em segredo.
